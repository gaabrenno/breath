Funciona no seu Linux

O instalador descobre o seu ambiente e coloca o Breath no lugar certo.

GNOME 45 a 50Os dois anéis na barra superior, com os detalhes ao passar o mouse.
KDE Plasma, XFCE, Cinnamon, MATE, BudgieDois ícones na bandeja. O clique abre o painel de detalhes junto do mouse.
Hyprland, Sway, i3O comando breath, pronto para a waybar, a polybar e o i3blocks.

Instale com um comando

Sem login e sem configuração. O Breath usa a sessão que o Claude Code já tem no seu computador e se atualiza sozinho.

curl -fsSL https://raw.githubusercontent.com/gaabrenno/breath/main/install.sh | bash

Instala a versão mais recente: v1.1.1. O que mudou

  • Claude Code instalado e logado com assinatura Pro ou Max
  • Funciona com o uso do site, do app e do Claude Code: é tudo o mesmo limite
Preciso fazer login no Breath?

Não. Ele só lê o acesso que o Claude Code já guarda no computador, nunca pede senha e nunca altera esse arquivo.

Meus dados saem do computador?

Só a consulta de uso, que vai direto para a Anthropic. Nada mais é enviado.

Como desinstalo?

Um comando remove tudo. Ele está no README do projeto.

Novidades

Cada versão diz se traz algo novo ou se só corrige o que já existia. As instalações recebem a versão nova sozinhas.
